# Power-BI-DAX-and-Data-Visualization

**Project Overview**

This project demonstrates data analysis and visualization using **Microsoft Power BI**. Multiple datasets were imported from Excel and transformed into meaningful visualizations, calculated columns, and DAX measures.

The main objective of this project is to practice **data cleaning, data visualization, calculated columns, and DAX functions** while creating an interactive analytical dashboard.

**Objectives**

- Importing Excel datasets into Power BI
- Understanding and preparing data for analysis
- Creating clustered column charts
- Creating line charts
- Creating pie charts
- Creating calculated columns using DAX
- Creating measures using DAX
- Calculating totals, counts, minimum and maximum values
- Identifying missing and valid records
- Presenting insights through a Power BI dashboard

**Datasets Used**

1. Amazingcart.xlsx

Used to analyze the number of orders placed across different countries.

Analysis performed:

- Country-wise order count
  
- Identification of countries with the highest number of orders

Visualization:
Clustered Column Chart

2. Customer_Data.xlsx

Customer/order transaction data used for order and sales analysis.

Analysis performed:
- Orders received by date
  
- Total sales

- Quantity and price analysis
  
- Calculated total price

3. Employee_Layoffs.xlsx

Employee layoffs dataset used to analyze layoffs across different locations.

Analysis performed:
- Number of layoffs by location

- Identification of locations with the highest number of layoffs

**Dashboard Visualizations**

1. Orders by Country

A **Clustered Column Chart** was created to show the number of orders placed in different countries.

Fields used:
- Axis → Country
  
- Values → Count of Order ID

The countries were sorted in **descending order** based on the number of orders.

2. Daily Orders Received

A **Line Chart** was created using the Customer Data to show the number of orders received on different dates.

Fields used:
- X-Axis → Order Date\

- Y-Axis → Count of Order ID

This visualization helps identify changes in order volume over time.

3. Layoffs by Location

A **Pie Chart** was created using the Employee Layoffs dataset.

**Fields used:**
- Legend → Location

- Values → Count of Location / Employee records

The visualization shows the distribution of layoffs across different locations.

4. Total Sales

A **Card visual** was created to display the total sales value.

DAX Calculated Column

A calculated column was created in the Customer Data table to calculate total price using quantity and product price.

**Several DAX measures were created to perform numerical and data-quality analysis.**

**Learning Outcome**

Through this project, practical experience in using Power BI for data analysis and visualization was gained. Learned how to import and prepare Excel datasets, create different types of charts, develop calculated columns, write DAX measures, and present analytical results through a dashboard.
This project strengthened understanding of Business Intelligence, Data Analytics, and Power BI reporting.
